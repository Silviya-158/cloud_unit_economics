# One-Week Programme Outline: Agentic AI Bootcamp

## Delivery assumption

The resources assume five structured bootcamp days between 18/08/2026 and 26/08/2026, with Thursday 20/08/2026 dedicated to the Amazon UK fulfilment centre industrial visit. If institutional scheduling uses Friday 21/08, Monday 24/08 or Tuesday 25/08 differently, the daily resources can be moved without changing the learning sequence.

## Programme philosophy

The bootcamp uses a hybrid teaching approach: every concept is followed by a practical activity. Students learn agentic AI as a controlled software engineering workflow: define the goal, design state, connect tools, retrieve grounded knowledge, pause for human review, test failure cases, and present evidence.

## Day 1 - Tuesday 18/08/2026: Agentic AI foundations and provider setup

**Theme:** From chatbot to controlled agent.

**Theory:** agent loop, workflow versus autonomy, model/provider choices, tool use, state, safety boundaries, financial inclusivity.

**Practical:** run the provider checker; verify Ollama models; try Groq/OpenAI/Gemini/Anthropic/DeepSeek if keys are available; compare outputs and latency; use mimic fallback if no provider is available.

**Output:** a working provider route and a first grounded answer from at least one available model.

## Day 2 - Wednesday 19/08/2026: LangGraph, tools, state and routing

**Theme:** Build an agent as a graph, not a prompt.

**Theory:** StateGraph, nodes, edges, tool functions, risk assessment, logging, recovery from tool failure.

**Practical:** build a fulfilment-centre operations support workflow using LangGraph; call tools such as knowledge lookup, risk assessment, calculator, observation retrieval and human-review packet creation.

**Output:** a working graph-based prototype that can answer a realistic operations-support query and identify when review is required.

## Day 3 - Thursday 20/08/2026: Amazon UK fulfilment centre industrial visit

**Theme:** Observe real operations before designing agents.

**Theory bridge:** automation boundaries, human-robot collaboration, fulfilment-centre workflows, data capture points, safety-critical decisions, exception handling.

**Practical:** use the observation worksheet; capture workflows, data signals, human decisions, exception points and possible agent use cases.

**Output:** structured observation notes ready for RAG, process mapping and capstone ideation.

## Day 4 - Friday 21/08/2026: RAG, human-in-the-loop and responsible automation

**Theme:** Ground the agent and control its actions.

**Theory:** retrieval augmented generation, prompt injection risks, evidence use, approval gates, reviewer options, sensitive actions and limitations.

**Practical:** build a RAG assistant over the bootcamp knowledge base and industrial-visit observations; add a human-in-the-loop checkpoint for high-risk outputs.

**Output:** a grounded assistant that cites local evidence and pauses for review on safety, performance or escalation requests.

## Day 5 - Wednesday 26/08/2026: Capstone agent build, evaluation and demos

**Theme:** Present a realistic, tested, responsible agent.

**Theory:** evaluation design, trace review, test sets, failure modes, demo storytelling, production-readiness checklist.

**Practical:** teams build a capstone fulfilment-centre support agent or another bounded agent; run test cases; complete the evaluation rubric; present a short demo.

**Output:** team demonstration, evaluation sheet, human-review rationale and next-step improvement plan.

## Optional consolidation clinics - Monday 24/08/2026 and Tuesday 25/08/2026

Use these as drop-in studio time, independent build time, coding clinics, or reflective write-up sessions if the timetable allows.
