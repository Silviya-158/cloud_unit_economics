# Human-in-the-Loop Review Card

Use this card whenever an agent proposes a sensitive, risky, irreversible or uncertain action.

## Reviewer decision

- [ ] Approve exactly as proposed
- [ ] Approve with edits
- [ ] Reject
- [ ] Ask for more evidence
- [ ] Escalate to a responsible member of staff

## Evidence checklist

- [ ] The agent showed the original user request.
- [ ] The agent showed the retrieved evidence or tool results.
- [ ] The agent explained why review is needed.
- [ ] The agent stated the risks and limitations.
- [ ] The action is logged.
