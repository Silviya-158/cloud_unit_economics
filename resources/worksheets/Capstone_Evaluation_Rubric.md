# Capstone Evaluation Rubric

| Criterion | Excellent | Strong | Developing |
|---|---|---|---|
| Problem definition | Narrow, useful, realistic, user-centred | Mostly clear and bounded | Too broad or unclear |
| Agent architecture | Clear LangGraph state, nodes, edges and tools | Some graph structure visible | Mostly a prompt, little structure |
| Tool use | Tools are purposeful and tested | Tools work but are limited | Tools are unclear or unreliable |
| Human-in-the-loop | Review gates are justified and demonstrated | Review exists but is basic | Review is missing or tokenistic |
| Grounding / RAG | Uses evidence and admits gaps | Some evidence used | Ungrounded claims common |
| Evaluation | Normal, edge and failure cases tested | Some tests completed | Demo only, little testing |
| Responsible AI | Safety, privacy and accountability considered | Some risks considered | Risks not addressed |
| Presentation | Clear demo and honest reflection | Mostly clear | Difficult to follow |
